# 01. 점수 배열 프로그램 — 1차 완성본 상세 해설

> **원본 보존**: 이 문서는 GitHub의 01_ScoreArray/main.c 전체를 그대로 수록합니다. 기존 C 코드는 변경하지 않았습니다. 설명은 학생이 교수님 질문에 스스로 답할 수 있도록 작성했습니다.

## 1. 과제 목적과 전체 흐름

학생 5명의 점수를 차례로 입력받아 하나의 정수 배열에 저장하고, 다시 화면에 출력하는 프로그램입니다. **여러 개의 같은 종류 데이터**를 다루므로 숫자 변수 다섯 개가 아니라 **배열**을 선택했습니다.

동작 순서: (1) 다섯 개 점수를 저장할 공간 확보 → (2) 반복해서 입력 → (3) 입력 실패 시 종료 → (4) 저장된 배열을 처음부터 끝까지 출력 → (5) 정상 종료.

단순 프로그램이라 함수를 억지로 여러 개 만들지 않았습니다. 8~11장을 배운 뒤에는 같은 코드를 함수로 분리하여 역할과 반환값을 연습할 수 있습니다. 그 응용 코드는 ../Applied_8to11/01_ScoreArray/main.c에 별도로 있습니다.

## 2. 프로그램 전체 코드 — 원본과 동일

### 01_ScoreArray/main.c

~~~c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#define SIZE 5

int main(void)
{
    int i;
    int score[SIZE];

    printf("5명의 점수를 입력하시오.\n");

    for (i = 0; i < SIZE; i++)
    {
        printf("%d번째 점수: ", i + 1);
        if (scanf("%d", &score[i]) != 1)
        {
            printf("점수를 숫자로 입력해야 합니다.\n");
            return 1;
        }
    }

    printf("\n입력한 점수\n");
    for (i = 0; i < SIZE; i++)
    {
        printf("scores[%d] = %d\n", i, score[i]);
    }

    return 0;
}
~~~


## 3. 문장별 상세 해설과 선택 이유

### 3-1. 전처리 지시문 세 개

- **#define _CRT_SECURE_NO_WARNINGS**: Visual Studio가 scanf 함수에 대해 표시하는 특정 보안 경고를 억제합니다. 숫자가 0~100인지 자동 확인하지는 않습니다. GCC에서는 실질적으로 이 프로그램의 동작에 영향을 주지 않습니다.
- **#include <stdio.h>**: printf와 scanf 함수의 선언을 제공하는 표준 입출력 헤더입니다. 화면 출력과 키보드 입력을 하기 위해 필요합니다.
- **#define SIZE 5**: SIZE를 숫자 5로 치환합니다. 이것은 **전역변수가 아닙니다**. 배열 크기와 반복 종료 조건에 똑같은 수를 사용하기 위해 만들었습니다. 학생 수가 달라지면 이 한 값을 중심으로 수정할 수 있습니다. 단, 안내 문자열 '5명의 점수'는 자동 수정되지 않습니다.

### 3-2. main, i, score

- **int main(void)**: 실행이 시작되는 함수입니다. void는 전달받는 인자가 없고, int는 종료 결과를 정수로 돌려준다는 뜻입니다.
- **int i;**: 반복 중 현재 배열 칸 번호를 나타냅니다. 함수 **내부**의 일반 변수입니다. 별도의 전역변수를 선언한 것이 아닙니다.
- **int score[SIZE];**: 정수 다섯 개의 저장 공간을 만듭니다. 0번, 1번, 2번, 3번, 4번 칸만 존재합니다. 처음에는 값이 지정되지 않으므로 입력한 뒤 사용해야 합니다.
- 배열이 없었다면 score1부터 score5까지 각각 선언하고 다섯 번 입력·출력 코드를 작성해야 했을 것입니다. 학생 수가 증가하면 이 방식은 비효율적입니다.

### 3-3. 첫 번째 for문이 0부터 시작하는 이유

**for (i = 0; i < SIZE; i++)**는 초기식 → 조건 검사 → 본문 실행 → i 증가를 반복합니다.

| 반복 회수 | 반복 중 i | 점수를 저장할 배열 원소 | 화면 안내 |
|---|---:|---|---|
| 1회 | 0 | score[0] | 1번째 점수 |
| 2회 | 1 | score[1] | 2번째 점수 |
| 3회 | 2 | score[2] | 3번째 점수 |
| 4회 | 3 | score[3] | 4번째 점수 |
| 5회 | 4 | score[4] | 5번째 점수 |
| 검사 후 종료 | 5 | 접근하면 안 됨 | 5 < 5는 거짓 |

**i <= SIZE**로 쓰면 i가 5일 때도 실행되어 존재하지 않는 score[5]를 참조할 위험이 있습니다. **i < SIZE**가 필요한 가장 중요한 이유입니다.

**printf("%d번째 점수: ", i + 1)**에서 i에 1을 더하는 것은 사람에게 보여주는 순번만 1부터 시작시키기 위해서입니다. 배열 위치 i 자체는 바뀌지 않습니다.

### 3-4. scanf, & 연산자, 반환값 검사

**scanf("%d", &score[i])**는 정수 하나를 입력받아 score[i]가 위치한 곳에 저장합니다.

- %d: 정수를 입력받는 형식 지정자.
- score[i]: 해당 원소의 **값**을 뜻하는 표현.
- &score[i]: 해당 원소의 **주소**를 뜻하는 표현. scanf는 저장할 위치를 알아야 하므로 주소를 전달합니다. 이것이 11장의 포인터 개념과 연결됩니다.
- **!= 1**: 저장에 성공한 항목의 개수가 1이 아니면 입력 실패로 판단합니다. 문자 입력이나 입력 종료가 한 예입니다.
- **return 1**: 지금은 더 진행하지 않고 오류 상태로 프로그램을 끝냅니다.

왜 검사할까요? 사용자가 문자를 입력했을 때 올바른 정수가 없는 상태로 계속 출력하면 잘못된 값이 보일 수 있기 때문입니다. 다만 현 코드에는 **잘못된 정수 범위(예: -20, 900)를 거부하는 검사**가 없습니다. '숫자냐'만 검사합니다.

### 3-5. 두 번째 for문과 출력 문자열

첫 반복문은 **입력**, 둘째 반복문은 **출력**만 담당합니다. 입력이 다 끝난 다음 출력하므로 흐름을 설명하기 쉽습니다.

**printf("scores[%d] = %d\n", i, score[i])**에서 첫 번째 %d는 배열 번호 i, 두 번째 %d는 실제 저장값 score[i]입니다. \n은 줄바꿈입니다.

주의: 실제 배열 이름은 **score**이고, 출력 문자열의 **scores**는 사람이 읽을 문자열일 뿐입니다. 원본을 그대로 보존했기 때문에 이름 차이를 수정하지 않았습니다.

### 3-6. return 0

마지막의 **return 0**은 정상 종료를 뜻합니다. 앞의 **return 1**과 의미가 다릅니다. 값이 호출자인 운영 환경으로 전달되는 것이지 점수 배열을 출력하는 명령은 아닙니다.

## 5. 8~11장과의 관련성

| 단원 | 관련 개념 | 이 프로그램에서 쓰이는 위치 |
|---|---|---|
| 8장 함수 | main, printf, scanf | 시작 함수와 표준 라이브러리 함수 호출 |
| 9장 변수 범위·재귀 | 별도의 학습 기능을 추가하지 않음 | 여기서 재귀 호출을 강제로 만들 이유가 없음 |
| 10장 배열 | 배열 선언·인덱스·반복 처리 | score[SIZE], score[i] |
| 11장 포인터 | 주소 연산자 | &score[i]로 scanf에 저장 위치 전달 |

별도로 선언한 전역변수는 없고, main 안의 일반 변수만 사용합니다. SIZE는 전처리 상수입니다.

## 6. 교수님이 물어볼 가능성이 큰 질문

**Q1. 왜 배열을 썼나요?**  
A. 같은 종류의 데이터를 한 이름으로 관리하고, 반복문으로 쉽게 입력·출력하기 위해서입니다.

**Q2. 왜 i가 0부터 시작하나요?**  
A. C 배열의 첫 원소가 0번이기 때문입니다. 다섯 칸은 0~4번입니다.

**Q3. i < SIZE를 i <= SIZE로 바꾸면요?**  
A. 배열의 다섯 칸을 넘어 score[5]를 접근할 수 있어 잘못된 메모리 접근이 됩니다.

**Q4. i + 1은 i를 증가시키나요?**  
A. 아닙니다. 출력할 때만 1을 더합니다. 반복문에서 i를 증가시키는 것은 i++입니다.

**Q5. scanf 앞에 &를 붙인 이유는요?**  
A. 읽은 점수를 저장할 배열 원소의 주소를 전달하기 위해서입니다.

**Q6. != 1을 확인한 이유는요?**  
A. 정수 하나를 정상적으로 읽었는지 확인하려는 것입니다. 실패 시 잘못된 값 사용을 방지합니다.

**Q7. 왜 for문이 두 개 있나요?**  
A. 모든 점수를 저장한 후 전체를 출력하기 위해 입력과 출력 작업을 나눴습니다.

**Q8. return 0과 1이 다른 이유는요?**  
A. 0은 정상 종료, 1은 입력 실패 시 오류 종료를 나타냅니다.

**Q9. 코드를 함수로 나누면 무엇이 좋아지나요?**  
A. 입력, 출력, 합계 계산 등을 각각 맡길 수 있어서 수정과 재사용이 쉬워집니다. 별도 응용 버전에서 확인할 수 있습니다.

## 7. 한계, 확인할 점, 스스로 수정해 보기

- **점수 범위 검사 없음**: -1과 200도 정수이므로 통과합니다. 이것은 프로그램이 0~100점만 받도록 설계되지는 않았기 때문입니다.
- **숫자가 아닌 입력**: 메시지를 출력한 후 종료합니다. 재입력 기능은 없습니다.
- **출력 배열 이름 불일치**: scores라는 문구는 오타에 가깝지만 실행 결과의 값에는 영향이 없습니다.
- **합계·평균 없음**: 원래 목표가 입력과 출력이므로 구현하지 않았습니다.
- **성공 시 리턴값**: main 마지막에서 0입니다. 수치 계산의 결과를 반환하는 것이 아닙니다.
