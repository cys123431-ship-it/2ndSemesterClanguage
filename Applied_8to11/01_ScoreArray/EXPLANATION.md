# 01. 점수 배열 프로그램 — 8~11장 응용 버전 상세 해설

> **별도 응용판**: 기존 **01_ScoreArray/main.c는 수정하지 않았습니다.** 이 문서와 함께 있는 응용판 main.c의 전체 코드를 실었으며, 직접 입력·출력하던 원본을 함수 중심으로 확장한 이유를 설명합니다.

## 1. 왜 원본에서 응용했나?

원본은 학생 5명의 점수를 입력받은 뒤 출력합니다. 배열과 반복문을 배우기에는 충분하지만, 8장에서 배운 **함수의 매개변수와 반환값**을 직접 사용하기엔 기능이 적습니다.

응용판에서는 원래 입력과 출력을 유지하면서 **합계·평균·최고점**을 추가했습니다. 점수 데이터가 있으면 자연스럽게 필요해지는 기능이므로 무리한 추가가 아닙니다. 각 작업을 함수로 분리하고 main에는 작업 순서가 보이게 했습니다.

~~~text
main
 ├─ InputScores(score)  : 다섯 명의 점수 입력과 범위 검사
 ├─ PrintScores(score)  : 원래 배열 출력
 ├─ SumScores(score)    : 다섯 점수의 합계 반환
 └─ MaxScore(score)     : 최고점 반환
main에서 평균 계산과 요약 출력
~~~

배우지 않은 어려운 자료구조, 동적 할당, 전역변수, 재귀 호출은 쓰지 않았습니다.

## 2. 응용판 main.c 전체 코드 — 실제 파일과 동일

### Applied_8to11/01_ScoreArray/main.c

~~~c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#define SIZE 5

// 사용할 함수를 main보다 먼저 알려 줍니다.
int InputScores(int score[]);
void PrintScores(int score[]);
int SumScores(int score[]);
int MaxScore(int score[]);

int main(void)
{
    int score[SIZE];
    int sum;
    int max;

    if (InputScores(score) == 0)
    {
        printf("입력 오류로 프로그램을 종료합니다.\n");
        return 1;
    }

    PrintScores(score);

    sum = SumScores(score);
    max = MaxScore(score);

    printf("점수 합계: %d\n", sum);
    printf("점수 평균: %.1f\n", (double)sum / SIZE);
    printf("최고 점수: %d\n", max);

    return 0;
}

// 배열에 다섯 명의 점수를 입력합니다. 성공하면 1을 돌려줍니다.
int InputScores(int score[])
{
    int i;

    for (i = 0; i < SIZE; i++)
    {
        while (1)
        {
            printf("%d번째 점수(0~100): ", i + 1);

            if (scanf("%d", &score[i]) != 1)
            {
                return 0;
            }

            if (score[i] >= 0 && score[i] <= 100)
            {
                break;
            }

            printf("점수는 0부터 100까지 입력하세요.\n");
        }
    }

    return 1;
}

// 배열에 저장된 점수를 차례대로 출력합니다.
void PrintScores(int score[])
{
    int i;

    printf("\n입력한 점수\n");
    for (i = 0; i < SIZE; i++)
    {
        printf("score[%d] = %d\n", i, score[i]);
    }
}

// 합계를 계산해서 main에 돌려줍니다.
int SumScores(int score[])
{
    int i;
    int sum = 0;

    for (i = 0; i < SIZE; i++)
    {
        sum = sum + score[i];
    }

    return sum;
}

// 가장 큰 점수를 찾아 main에 돌려줍니다.
int MaxScore(int score[])
{
    int i;
    int max = score[0];

    for (i = 1; i < SIZE; i++)
    {
        if (score[i] > max)
        {
            max = score[i];
        }
    }

    return max;
}
~~~


## 3. main 부분을 먼저 이해하기

### 3-1. 네 함수 선언은 무엇인가?

코드 맨 앞의 **int InputScores(int score[]);**, **void PrintScores(int score[]);**, **int SumScores(int score[]);**, **int MaxScore(int score[]);**는 함수 원형입니다.

C는 코드를 위에서 아래로 읽으므로 main 아래에 있는 함수들을 main이 호출하려면 함수의 이름과 인자·결과 종류를 미리 알려주어야 합니다.

**void**와 **int**의 구별: 출력만 하는 PrintScores는 반환할 계산값이 없으므로 void입니다. SumScores와 MaxScore는 계산한 결과를 main이 사용해야 하므로 int입니다. InputScores는 성공(1) 또는 실패(0)를 알려주기 위해 int를 반환합니다.

함수 이름은 임의로 붙일 수 있지만, 목적을 이해할 수 있게 Input/Print/Sum/Max라는 뜻이 드러나도록 했습니다.

### 3-2. main에 int score[SIZE], int sum, int max가 있는 이유

**score**는 학생 5명 점수를 보관하는 원래 배열입니다. **sum**과 **max**는 각각 반환값을 받아 저장하는 정수 변수입니다.

**if (InputScores(score) == 0)**는 입력에 실패했을 때 전체 프로그램을 종료하도록 합니다. 성공하면 PrintScores, SumScores, MaxScore 순서로 이동합니다.

이로써 main은 모든 계산 세부사항을 직접 작성하는 대신 **언제 어떤 작업이 필요한지**를 보여 주는 역할을 합니다.

### 3-3. 배열은 어떻게 함수로 전달되나?

예를 들어 다음 호출을 봅니다.

- main: **int score[SIZE];**
- 호출: **InputScores(score);**
- 함수 선언: **int InputScores(int score[]);**

여기서 함수가 받는 배열 매개변수는 호출한 쪽 배열을 가리켜 그 원소에 접근합니다. 함수 안에서 score[i]에 값을 저장하면 main에서 사용하는 배열에도 같은 값이 있습니다.

'배열 열 개를 새로 복사해서 넘기는 것'과는 다릅니다. 배열 이름을 함수 인자로 전달하는 표현은 11장의 포인터와 연결되지만, 초보자에게 복잡한 포인터 연산을 강요하지는 않습니다.

## 4. 함수별로 왜 이렇게 작성했는가?

### 4-1. InputScores — 왜 while(1)을 for문 안에 넣었나?

바깥 **for**는 첫 번째부터 다섯 번째 학생으로 이동합니다. 안쪽 **while(1)**은 **현재 학생의 점수가 유효할 때까지** 반복합니다.

- scanf("%d", &score[i])가 **1이 아니라면**, 숫자를 올바르게 읽지 못했으므로 0을 반환하고 프로그램이 종료됩니다.
- score[i]가 **0 이상이고 100 이하**이면 break로 현재 학생의 입력 반복을 끝냅니다.
- -5, 125 등 정수이지만 점수로 부적절한 숫자는 오류 안내 후 **같은 학생에게 다시 질문**합니다.

왜 숫자가 아닌 입력에서는 재입력하지 않을까요? scanf에 입력되지 못한 문자가 남아 있는 문제를 처리하려면 별도 입력 버퍼 정리가 필요하기 때문입니다. 학습 범위 안에서 혼란을 줄이려 우선 안전하게 종료하도록 했습니다.

**성공하면 return 1, 실패하면 return 0**이라는 약속은 main과 InputScores가 통신하는 간단한 방법입니다.

### 4-2. PrintScores — 왜 void인가?

이 함수의 목적은 출력이므로 main으로 숫자를 돌려줄 필요가 없습니다. 함수 안에서 for문으로 score[0]부터 score[4]까지 출력합니다. 다른 사람이 나중에 합계 앞뒤에 배열을 여러 번 출력하길 원해도 이 함수를 다시 호출하면 됩니다.

### 4-3. SumScores — 왜 sum=0부터 시작하나?

합계를 계산하는 변수는 아직 아무 점수도 더하지 않았으므로 **0으로 초기화**합니다.

**sum = sum + score[i];**는 이전 합계에 현재 점수를 더해 다시 sum에 저장합니다. 예를 들어 85, 90, 73을 입력했다면 합계가 85 → 175 → 248로 변합니다.

함수 끝의 **return sum**은 계산된 합계를 main으로 전달합니다. main은 이를 **sum = SumScores(score)**로 받습니다.

### 4-4. MaxScore — 왜 max=score[0]인가?

최댓값을 구할 때 **0으로 시작하면 안 되는 경우**가 있습니다. 모든 원소가 음수인 일반 배열이면 0을 최댓값으로 잘못 선택하기 때문입니다. 이 응용판 점수는 0~100이지만, 기본 원리를 정확하게 지키기 위해 **첫 원소를 최고점 후보**로 삼습니다.

이후 **i=1**부터 검사하는 이유는 score[0]을 이미 후보로 선택했기 때문입니다. **score[i] > max**일 때만 값을 교체하므로, 최종적으로 가장 큰 값을 얻습니다.

### 4-5. 평균에서 (double)sum / SIZE를 쓴 이유

C에서 **정수 / 정수**는 정수 나눗셈이므로 소수점 이하가 버려집니다. 예를 들어 sum=437이면 **437 / 5 = 87**입니다.

**(double)sum / SIZE**는 sum을 실수로 계산하게 만들어 **87.4**를 얻습니다. **%.1f**는 소수 첫째 자리까지 표시합니다.

왜 더 어려운 수학 라이브러리를 쓰지 않았나요? 다섯 개 점수의 평균은 단순 사칙연산으로 계산되기 때문입니다.

## 6. 원본과 비교: 무엇을 왜 바꿨나?

| 1차 완성본 | 응용판 | 변경 이유 |
|---|---|---|
| main이 입력과 출력 모두 처리 | InputScores, PrintScores 분리 | 함수의 역할·호출·매개변수 학습 |
| 정수인지 여부만 확인 | 0~100 범위 확인 | 점수라는 자료의 의미에 맞는 입력 |
| 합계·평균·최고점 없음 | SumScores, MaxScore와 평균 계산 추가 | 배열에 저장된 데이터의 자연스러운 활용 |
| 원소 표시 문자열 scores | score와 일치시킴 | 코드와 출력 명칭 일관성 |

원본 폴더는 그대로 보존했습니다. 두 버전의 변경은 목적이 다른 **별도 학습 단계**입니다.

## 7. 교수님 예상 질문

**Q1. 함수를 네 개로 나눈 이유는요?**  
A. 입력, 출력, 합계, 최댓값은 각각 다른 일을 하기 때문입니다. main에서는 작업 순서가 보이게 했습니다.

**Q2. InputScores가 왜 int를 반환하나요?**  
A. 올바른 입력이면 1, 실패하면 0을 돌려줘 main에서 오류 여부를 판단하도록 했기 때문입니다.

**Q3. void PrintScores는 결과가 없나요?**  
A. 화면 출력이라는 작업은 수행하지만 main에 숫자를 반환할 필요는 없습니다.

**Q4. 함수 인자로 score를 넘기면 새 배열을 복사하나요?**  
A. 아닙니다. 배열의 원소에 접근할 수 있는 위치 정보가 전달되어 원래 배열을 사용합니다.

**Q5. for와 while을 함께 사용한 이유는요?**  
A. for는 다음 학생으로 이동하고, while은 현재 학생에게 유효한 점수를 받을 때까지 반복하기 때문입니다.

**Q6. 평균에서 (double)을 사용하지 않으면요?**  
A. 정수끼리 나누면 소수 부분이 버려지므로 정확한 평균을 출력하지 못할 수 있습니다.

**Q7. max를 0이 아니라 score[0]부터 시작한 이유는요?**  
A. 배열의 실제 원소를 첫 후보로 정해 일반적인 최댓값 찾기 원리를 지키기 위해서입니다.

**Q8. 전역변수를 썼나요?**  
A. 쓰지 않았습니다. score, sum, max, i는 각각 함수 안에서 사용하는 일반 변수입니다. SIZE는 전처리 상수입니다.

## 8. 적용한 단원과 적용하지 않은 단원

- **8장**: 함수 선언, 호출, 매개변수, void/int 반환.
- **9장**: 별도 재귀를 사용하지 않았습니다. 다섯 점수 합계를 재귀로 처리하는 것보다 반복문이 단순하고 자연스럽기 때문입니다.
- **10장**: 배열과 순차 접근, 합계와 최댓값 탐색.
- **11장**: scanf에 주소(&) 전달, 배열을 함수 인자로 전달하는 기본 관계.
